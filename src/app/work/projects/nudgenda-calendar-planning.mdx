    <ul style={{ paddingLeft: '1.25rem', display: 'flex', flexDirection: 'column', gap: '0.5rem' }}>
      <li style={{ listStyleType: 'disc' }}>
        <Text variant="body-default-m" onBackground="neutral-strong">
          <Text as="span" variant="body-strong-m">Native calendar integration:</Text> On Android, calendar permissions provide access to the device's synchronized calendars. Event changes use the phone's existing account synchronization to reach Google Calendar.
        </Text>
      </li>
      <li style={{ listStyleType: 'disc' }}>
        <Text variant="body-default-m" onBackground="neutral-strong">
          <Text as="span" variant="body-strong-m">A browser-specific connection:</Text> The web flow uses Google Identity Services and a temporary in-memory access token to call Google Calendar directly.
        </Text>
      </li>
      <li style={{ listStyleType: 'disc' }}>
        <Text variant="body-default-m" onBackground="neutral-strong">
          <Text as="span" variant="body-strong-m">Swappable calendar sources:</Text> Android, Google web, and demo repositories support the same planning experience, with demo events available before a calendar is connected.
        </Text>
      </li>
    </ul>

  <Column fillWidth gap="16">
    <Heading as="h2" variant="heading-strong-l">The Product Experience</Heading>
    <Text variant="body-default-m" onBackground="neutral-medium">
      The Today view presents tappable schedule blocks and event details. A pull-down gesture opens the full-page chat interface, while calendar settings bring source selection and Android permissions into the app. The calendar workflow supports reading, creating, updating, deleting, and opening system events.
    </Text>
    <Text variant="body-default-m" onBackground="neutral-medium">
      The project combines Expo Router and React Native with dedicated calendar adapters, keeping screen design separate from platform-specific calendar access.
    </Text>
