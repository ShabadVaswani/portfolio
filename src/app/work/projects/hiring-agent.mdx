    <Text variant="body-default-m" onBackground="neutral-medium">

    <ul style={{ paddingLeft: '1.25rem', display: 'flex', flexDirection: 'column', gap: '0.5rem' }}>
      <li style={{ listStyleType: 'disc' }}>
        <Text variant="body-default-m" onBackground="neutral-strong">
          <Text as="span" variant="body-strong-m">Full pipeline UI:</Text> Wrapped the Python resume-to-score pipeline in a Next.js app with PDF upload, model selection, and live score breakdown.

      </li>
      <li style={{ listStyleType: 'disc' }}>
        <Text variant="body-default-m" onBackground="neutral-strong">
          <Text as="span" variant="body-strong-m">Structured scoring:</Text> Surfaces open source, projects, production experience, and technical skills with written evidence and fairness rules that exclude school, GPA, and location.
        </Text>
      </li>
      <li style={{ listStyleType: 'disc' }}>
        <Text variant="body-default-m" onBackground="neutral-strong">
          <Text as="span" variant="body-strong-m">GitHub enrichment:</Text> Fetches and classifies repositories to strengthen project signals before evaluation.
        </Text>
      </li>
      <li style={{ listStyleType: 'disc' }}>
        <Text variant="body-default-m" onBackground="neutral-strong">
          <Text as="span" variant="body-strong-m">Bring your own model:</Text> Runs via OpenRouter with a per-request API key that is never stored server-side.
        </Text>
      </li>
      <li style={{ listStyleType: 'disc' }}>
        <Text variant="body-default-m" onBackground="neutral-strong">
          <Text as="span" variant="body-strong-m">GitHub OAuth:</Text> One-click Connect GitHub flow — no manual token paste. Tokens live in an encrypted httpOnly session cookie.
        </Text>
      </li>

    <Heading as="h2" variant="heading-strong-l">One-time production setup</Heading>
    <Text variant="body-default-m" onBackground="neutral-medium">
      Configure GitHub OAuth and Vercel env vars once on the hiring-agent Vercel project. Register OAuth on the stable Vercel portfolio URL only — not shabad.sbs. OpenRouter keys are entered by each visitor in the UI.
    </Text>
    <Heading as="h3" variant="heading-strong-m">Step 1 — GitHub OAuth app</Heading>
    <Text variant="body-default-m" onBackground="neutral-medium">
      Create an OAuth app at github.com/settings/developers. Use the Vercel portfolio URL only:
    </Text>
    <ul style={{ paddingLeft: '1.25rem', display: 'flex', flexDirection: 'column', gap: '0.5rem' }}>
      <li style={{ listStyleType: 'disc' }}>
        <Text variant="body-default-m" onBackground="neutral-strong">
          <Text as="span" variant="body-strong-m">Homepage URL:</Text> https://shabadportfolio.vercel.app/hiring-agent
        </Text>
      </li>
      <li style={{ listStyleType: 'disc' }}>
        <Text variant="body-default-m" onBackground="neutral-strong">
          <Text as="span" variant="body-strong-m">Authorization callback URL:</Text> https://shabadportfolio.vercel.app/hiring-agent/api/auth/github/callback
        </Text>
      </li>
    </ul>
    <Text variant="body-default-m" onBackground="neutral-medium">
      Copy the Client ID and generate a Client secret.
    </Text>
    <Heading as="h3" variant="heading-strong-m">Step 2 — Vercel environment variables</Heading>
    <Text variant="body-default-m" onBackground="neutral-medium">
      In the hiring-agent Vercel project → Settings → Environment Variables, add:
    </Text>
    <ul style={{ paddingLeft: '1.25rem', display: 'flex', flexDirection: 'column', gap: '0.5rem' }}>
      <li style={{ listStyleType: 'disc' }}>
        <Text variant="body-default-m" onBackground="neutral-strong">
          <Text as="span" variant="body-strong-m">GITHUB_CLIENT_ID</Text> — from Step 1
        </Text>
      </li>
      <li style={{ listStyleType: 'disc' }}>
        <Text variant="body-default-m" onBackground="neutral-strong">
          <Text as="span" variant="body-strong-m">GITHUB_CLIENT_SECRET</Text> — from Step 1
        </Text>
      </li>
      <li style={{ listStyleType: 'disc' }}>
        <Text variant="body-default-m" onBackground="neutral-strong">
          <Text as="span" variant="body-strong-m">GITHUB_SESSION_SECRET</Text> — long random string (32+ chars)
        </Text>
      </li>
      <li style={{ listStyleType: 'disc' }}>
        <Text variant="body-default-m" onBackground="neutral-strong">
          <Text as="span" variant="body-strong-m">NEXT_PUBLIC_APP_URL</Text> — https://shabadportfolio.vercel.app/hiring-agent (no trailing slash)
        </Text>
      </li>
    </ul>
    <Text variant="body-default-m" onBackground="neutral-medium">
      Redeploy after saving env vars.
    </Text>
