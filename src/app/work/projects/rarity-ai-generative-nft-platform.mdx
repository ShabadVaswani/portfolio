    <Heading as="h2" variant="heading-strong-l">Engineering Highlights</Heading>
    <ul style={{ paddingLeft: '1.25rem', display: 'flex', flexDirection: 'column', gap: '0.5rem' }}>
      <li style={{ listStyleType: 'disc' }}>
        <Text variant="body-default-m" onBackground="neutral-strong">
          <Text as="span" variant="body-strong-m">Generative AI Integration:</Text> Groq-backed endpoints generate prompt alternatives, names, descriptions, and traits. A Gemini image-generation integration returns artwork for the creation flow.
        </Text>
      </li>
      <li style={{ listStyleType: 'disc' }}>
        <Text variant="body-default-m" onBackground="neutral-strong">
          <Text as="span" variant="body-strong-m">Contract Services:</Text> The browser connects through an injected Ethereum wallet provider. Separate Ethers.js services call the ERC-721 contract and await transaction confirmation for minting and transfers.
        </Text>
      </li>
      <li style={{ listStyleType: 'disc' }}>
        <Text variant="body-default-m" onBackground="neutral-strong">
          <Text as="span" variant="body-strong-m">Local Development:</Text> Docker Compose brings the React frontend and Express backend together with source mounts and separate dependency volumes.
        </Text>
      </li>
    </ul>
  </Column>

  <Column fillWidth gap="16">
    <Heading as="h2" variant="heading-strong-l">From Prompt to NFT Metadata</Heading>
    <ol style={{ paddingLeft: '1.25rem', display: 'flex', flexDirection: 'column', gap: '0.5rem' }}>
      <li>
        <Text variant="body-default-m" onBackground="neutral-strong">
          <Text as="span" variant="body-strong-m">Shape the idea:</Text> Enter a text prompt and choose from Groq-generated refinements before creating the artwork.
        </Text>
      </li>
      <li>
        <Text variant="body-default-m" onBackground="neutral-strong">
          <Text as="span" variant="body-strong-m">Select the artwork:</Text> Generate images through Gemini or upload an existing image for the NFT workflow.
        </Text>
      </li>
      <li>
        <Text variant="body-default-m" onBackground="neutral-strong">
          <Text as="span" variant="body-strong-m">Describe the asset:</Text> Generate a name, description, and traits, then compute a trait score from an explicit lookup table. The score is a prototype heuristic rather than a market valuation.
        </Text>
      </li>
    </ol>
    <Text variant="body-default-m" onBackground="neutral-medium">
      The AI creation flow previews minting with a simulated transaction response. The separate contract service implements on-chain calls, while the Solidity contract manages owner-authorized minting, token URIs, and transfers. This distinction keeps the prototype's creative workflow separate from confirmed blockchain transactions.
    </Text>
